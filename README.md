One satirical sentence, 189 characters, roasting lawmakers who wrote the rules for artificial intelligence but cannot convert a file to PDF — entered in make.fun's “The Long Roast: Lawmakers and the File They Cannot Convert” bounty.

## The roast

> The lawmakers who wrote the rules for artificial intelligence still email their final draft to the intern with the subject line 'please turn this into a PDF' — and ask for it back on paper.

The sentence sets up the lawmakers' authority (they wrote the rules), then undercuts it with the one file they cannot convert — pinned to a concrete detail, the email subject line — and lands its punch on the last five words: they ask for the file back on paper, as if paper were the real file.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the sentence above to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`). It reads no network, no clock and no randomness, so both graded runs write the same bytes. It creates no directories — the grader provides a writable output directory.
